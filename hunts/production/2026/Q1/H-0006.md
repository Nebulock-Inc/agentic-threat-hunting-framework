# H-0006: Identity Provider Brute Force Hunt

## LEARN

**Hypothesis:** Attackers are performing password spray and brute force attacks against identity provider accounts to gain initial access.

Identity providers are the front door to SaaS and cloud; spray attacks against them are a common initial-access attempt that MFA should blunt but should still be detected.

## OBSERVE

**Data sources:** Okta system logs, Entra ID sign-in logs.

Expected signal: many failed authentications spread thinly across many accounts from a set of source IPs. Benign look-alikes include misconfigured SSO integrations, load testing, and password-reset campaigns.

## CHECK

### Queries Executed

```sql
-- Failed auth attempts per account
SELECT 
    user_email,
    source_ip,
    COUNT(*) as attempts,
    MIN(timestamp) as first_attempt,
    MAX(timestamp) as last_attempt
FROM okta_system_log
WHERE event_type = 'user.authentication.auth_via_mfa.FAILED'
AND timestamp >= DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY 1,2
HAVING attempts >= 5
ORDER BY attempts DESC;
```

### Finding

**F-001: Coordinated Password Spray Attack**
- **Target:** 847 user accounts
- **Source IPs:** 23 IP addresses (residential proxies)
- **Pattern:** 3-5 attempts per account every 30 minutes
- **Duration:** 72 hours
- **Passwords tested:** Common breached passwords from threat intel
- **Successful logins:** 0 (all MFA-protected)
