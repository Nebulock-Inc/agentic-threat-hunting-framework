## LEARN: Prepare the Hunt

### Hypothesis

**Behavioral Pattern:** An infostealer or unauthorized collection script is accessing browser credential stores, cryptocurrency wallet files, or SSH/cloud-config directories, then staging stolen data into a short-lived ZIP archive in Temp/AppData/user-profile paths before self-deleting or terminating to evade detection.

**Why It Matters:** Infostealer malware families (Lumma, Vidar, SHub/ClickFix, Chihuahua Stealer) commonly collect browser credentials, cookies, and cryptocurrency wallet data, compress it into a ZIP or similar archive in a temp directory, and remove staging artifacts to reduce forensic evidence before exfiltration. Validating this pattern across the environment closes a gap in existing detection coverage—several of the closest-matching detection rules (SSH key access followed by archiving, browser-store access by a stealer process, native archiving utility exfiltration) are currently inactive.

### ABLE Framework

**Actor:** N/A — no adversary-controlled or unauthorized actor identified (negative finding)

**Behavior:** Archive-then-stage-then-cleanup pattern:
1. Credential/wallet/SSH/cloud-config file access
2. ZIP/TAR archive creation in a temp or user path
3. Binary self-deletion or rapid artifact removal

**Location:**
- **macOS endpoints:** 54 SentinelOne agents, 2 CrowdStrike agents
- **Windows endpoints:** Limited coverage (1 host on Defender/Azure Event Hub)
- **Focus paths:**
  - macOS: `/tmp/`, `~/Library/Application Support/`, `~/Library/Keychains/`
  - Windows: `%TEMP%`, `%AppData%`, `C:\ProgramData\`

**Evidence:** 
- **File Events:** `file.path`, `file.name`, `file.create`, `file.modify`, `file.delete`
- **Process Events:** `process.name`, `process.command_line`, `parent.process.name`
- **Network Events:** Outbound connections from archive-creating processes
- **Correlation Window:** 30 minutes to 1 hour

## OBSERVE: Execute the Hunt

### Normal Behavior Baseline

**Legitimate Archive Activity:**
- **Application updaters:** Notion, Linear, Slack, Cursor, VS Code, Granola, Ollama, Signal, JetBrains Toolbox writing and cleaning up ZIP packages in cache/update directories
- **GitHub CLI:** `gh` downloading Actions run-log ZIP archives to `~/.cache/gh/`
- **AWS CLI:** Writing SSO/session cache files under `~/.aws/sso/cache` and `~/.aws/cli/cache`
- **gcloud:** Python writing credential files under `~/.config/gcloud`
- **SSH utilities:** `ssh`, `ssh-agent`, `ssh-keygen` creating/updating files in `.ssh/` (known_hosts, agent sockets, key pairs)
- **Safari import:** `com.apple.Safari.BrowserDataImportingService` reading/writing temporary Login Data files during Chrome-to-Safari import workflow
- **Package managers:** Homebrew, Python, Go test suites unpacking/creating archive test-data ZIPs (bsdtar, python3, go, ruby)
- **Self-deleting installers:** GoogleUpdater, Squirrel ShipIt, Sparkle Autoupdate, Spotify, vc_redist cleaning up temp copies after installation

### Suspicious Behavior Indicators

**Expected Observables for Infostealer Activity:**
1. **Processes:**
   - `zip`, `tar/bsdtar`, `ditto`, `7z`, `PowerShell Compress-Archive` with command-line references to credential, wallet, or cloud-config paths
   - Unfamiliar or short-lived binaries creating ZIP files in AppData/Temp/user-profile paths
   - Process self-deletion immediately following archive creation

2. **Network:**
   - Outbound connections from an archive-creating process shortly after staging a credential/wallet archive

3. **Files:**
   - Short or dox-style ZIP filenames in AppData, Temp, or user-profile directories
   - Browser credential store files: `Login Data`, `logins.json`, `key4.db`, cookies databases
   - Wallet files: Exodus, Electrum, MetaMask, `wallet.dat`
   - `.ssh`, `.aws`, `.config/gcloud` files

4. **Authentication:**
   - Anomalous authentication or privilege escalation following credential access

## CHECK: Validate and Pivot

### Methodology

**Multi-Phase Approach:**

**Phase 1:** Review existing findings, detection rules, and threat intelligence for archive-staging and infostealer patterns

**Phase 2:** Query ZIP creation events across Temp/AppData/user-profile paths by provider and process, then narrow to short/suspicious-named ZIPs via regex

**Phase 3:** Query non-browser process activity touching browser credential, wallet, SSH, and cloud-config paths, excluding known-benign processes

**Phase 4:** Correlate credential-path activity and ZIP creation on the same host within a 30-minute window

**Phase 5:** Search archive-tool command lines for credential/wallet/cloud-config path references

**Phase 6:** Search for binaries self-deleting from temp/user paths

**Phase 7:** Investigate any near-matches in detail, examining surrounding process, file, and network activity plus actor/entity context

### Hunt Queries

**Query 1: Suspiciously-Named ZIP Creation**

```sql
-- Search for ZIP files with short, dox-style, or random-hex names
-- in Temp/AppData/user-profile directories
SELECT
    time,
    endpoint.name,
    endpoint.uid,
    actor.user.name,
    process.name,
    process.command_line,
    file.path,
    file.name,
    file.size
FROM file_events
WHERE date >= now() - INTERVAL 14 DAYS
  AND event_type = 'creation'
  AND file.name LIKE '%.zip'
  AND (
    -- Temp directories
    file.path LIKE '/tmp/%'
    OR file.path LIKE '/var/tmp/%'
    OR file.path LIKE '%\\Temp\\%'
    OR file.path LIKE '%\\AppData\\%'
    OR file.path LIKE '%/Library/Caches/%'
  )
  -- Short or suspicious names (3-8 chars, hex patterns, dox-style)
  AND (
    LENGTH(REGEXP_REPLACE(file.name, '\\.zip$', '')) BETWEEN 3 AND 8
    OR file.name REGEXP '^[0-9a-f]{6,16}\\.zip$'
    OR file.name LIKE '%_dox.zip'
    OR file.name LIKE 'data%.zip'
    OR file.name LIKE 'creds%.zip'
  )
  -- Exclude known benign patterns
  AND process.name NOT IN ('bsdtar', 'unzip', 'ditto', 'curl', 'wget', 'homebrew', 'python3', 'go', 'ruby')
ORDER BY time DESC
LIMIT 100;
```

**Results:** All matches resolved to known benign sources:
- `bsdtar` unpacking Homebrew/Python/Go test data
- Claude plugin/skill ZIPs
- `curl` downloading Terraform binaries
- SentinelOne's own static AI library ZIP
- Single analyst-created test file (`cdr-r4.zip`)
- **No unfamiliar binary producing a short-named ZIP was found**

**Query 2: Non-Browser Access to Credential/Wallet Paths**

```sql
-- Search for processes other than browsers touching credential stores
SELECT
    time,
    endpoint.name,
    actor.user.name,
    process.name,
    process.file.path,
    parent.process.name,
    file.path,
    file.name,
    event_type
FROM file_events
WHERE date >= now() - INTERVAL 14 DAYS
  AND (
    -- Browser credential stores
    file.path LIKE '%/Login Data'
    OR file.path LIKE '%/logins.json'
    OR file.path LIKE '%/key4.db'
    OR file.path LIKE '%/Cookies'
    OR file.path LIKE '%/Web Data'
    
    -- Crypto wallets
    OR file.path LIKE '%/Exodus/%'
    OR file.path LIKE '%/Electrum/%'
    OR file.path LIKE '%/MetaMask/%'
    OR file.path LIKE '%/wallet.dat'
    
    -- SSH and cloud configs
    OR file.path LIKE '%/.ssh/%'
    OR file.path LIKE '%/.aws/%'
    OR file.path LIKE '%/.config/gcloud/%'
    OR file.path LIKE '%/Library/Keychains/%'
  )
  -- Exclude legitimate browsers and system processes
  AND process.name NOT IN (
    'Google Chrome', 'firefox', 'Safari', 'Microsoft Edge', 'Brave Browser',
    'ssh', 'ssh-agent', 'ssh-keygen', 'aws', 'gcloud', 'python3',
    'CloudKeychainProxy', 'com.apple.Safari.BrowserDataImportingService'
  )
ORDER BY time DESC
LIMIT 100;
```

**Results:** All activity attributed to legitimate sources:
- AWS CLI/Python (SSO cache)
- gcloud (Python credential files)
- ssh/ssh-agent/ssh-keygen (key management)
- Apple's Safari credential-import service
- CloudKeychainProxy (system process)
- Playwright/Electron test profiles
- Node module filename false positives (`@exodus/bytes`, `phantom` - not actual wallets)

**Query 3: Credential Access → Archive Correlation**

```sql
-- Correlate credential/wallet/SSH/cloud-config file access
-- with ZIP creation on the same host within 30-60 minutes
WITH credential_access AS (
  SELECT
    endpoint.uid,
    endpoint.name,
    time as access_time,
    actor.user.name,
    process.name as accessor_process,
    file.path as credential_path
  FROM file_events
  WHERE date >= now() - INTERVAL 14 DAYS
    AND (
      file.path LIKE '%/Login Data'
      OR file.path LIKE '%/.ssh/%'
      OR file.path LIKE '%/.aws/%'
      OR file.path LIKE '%/Library/Keychains/%'
      OR file.path LIKE '%/wallet%'
    )
),
archive_creation AS (
  SELECT
    endpoint.uid,
    endpoint.name,
    time as archive_time,
    actor.user.name,
    process.name as archiver_process,
    process.command_line,
    file.path as archive_path
  FROM file_events
  WHERE date >= now() - INTERVAL 14 DAYS
    AND event_type = 'creation'
    AND (file.name LIKE '%.zip' OR file.name LIKE '%.tar%' OR file.name LIKE '%.tgz')
    AND (
      file.path LIKE '/tmp/%'
      OR file.path LIKE '%\\Temp\\%'
      OR file.path LIKE '%\\AppData\\%'
    )
)
-- Find co-occurrences within 30-60 minute window
SELECT
    ca.endpoint.name,
    ca.access_time,
    ca.credential_path,
    ca.accessor_process,
    ac.archive_time,
    ac.archive_path,
    ac.archiver_process,
    ac.command_line,
    TIMESTAMPDIFF(MINUTE, ca.access_time, ac.archive_time) as minutes_between
FROM credential_access ca
JOIN archive_creation ac
    ON ca.endpoint.uid = ac.endpoint.uid
    AND ac.archive_time BETWEEN ca.access_time AND ca.access_time + INTERVAL 60 MINUTE
ORDER BY ca.access_time DESC
LIMIT 50;
```

**Results:** Two co-occurrences found, both benign and unrelated process pairs:
1. OrbStack Helper touching `.ssh/config` with Numbers writing a temp `Index.zip` (separate workflows)
2. `ssh-keygen` writing a `.pub` key with `go/ruby` writing Go-module test ZIPs (test suites)

**Query 4: Archive Tool Command Lines with Credential Paths**

```sql
-- Search zip/tar/ditto/7z command lines for credential/wallet paths
SELECT
    time,
    endpoint.name,
    actor.user.name,
    process.name,
    process.command_line,
    parent.process.name
FROM process_events
WHERE date >= now() - INTERVAL 14 DAYS
  AND process.name IN ('zip', 'tar', 'bsdtar', 'ditto', '7z', 'gzip', 'bzip2')
  AND (
    process.command_line LIKE '%/.ssh/%'
    OR process.command_line LIKE '%/.aws/%'
    OR process.command_line LIKE '%/gcloud/%'
    OR process.command_line LIKE '%/Login Data%'
    OR process.command_line LIKE '%/Keychain%'
    OR process.command_line LIKE '%/wallet%'
    OR process.command_line LIKE '%credential%'
  )
ORDER BY time DESC
LIMIT 50;
```

**Results:** **One match found** - investigated in detail below:
- `bsdtar tar czf /tmp/kc.tgz /Users/analyst/Library/Keychains/login.keychain-db`
- Occurred on analyst's MacBook Pro, part of test harness activity

**Query 5: Process Self-Deletion from Temp Paths**

```sql
-- Search for processes deleting their own binary
SELECT
    time,
    endpoint.name,
    actor.user.name,
    process.name,
    process.file.path as process_binary,
    process.command_line,
    file.path as deleted_file
FROM file_events
WHERE date >= now() - INTERVAL 14 DAYS
  AND event_type = 'deletion'
  AND (
    file.path LIKE '/tmp/%'
    OR file.path LIKE '%\\Temp\\%'
    OR file.path LIKE '%\\AppData\\%'
    OR file.path LIKE '%/Library/Caches/%'
  )
  -- File being deleted is an executable
  AND (file.name LIKE '%.exe' OR file.name LIKE '%.dll' OR file.name LIKE '%.bin')
ORDER BY time DESC
LIMIT 50;
```

**Results:** All matches were legitimate updaters and installers:
- Chrome, GoogleUpdater, Squirrel ShipIt, Sparkle Autoupdate
- Spotify, Ollama, tern, JetBrains Toolbox, vc_redist
- pytest virtualenv cleanup, synergy-core temp cleanup
- **No self-deletion immediately following ZIP creation was observed**

### Telemetry Gaps Identified

**Critical Gaps:**

1. **File-Read Telemetry Not Captured**
   - **Impact:** Silent read-only theft of browser credential database, wallet file, or SSH key would be invisible
   - **Recommendation:** Enable file-read monitoring on high-value paths (credential stores, wallets, .ssh)
   - **Prior Hunts Affected:** This limitation was also flagged in hunts from October 30, 2024 and October 10, 2024

2. **Limited Windows Coverage**
   - **Current:** 1 Windows host (Microsoft Defender + Azure Event Hub) vs. 54 macOS hosts (SentinelOne)
   - **Impact:** AppData-based Windows stealer behavior largely untestable
   - **Recommendation:** Expand Windows EDR deployment or increase Defender/Event Hub coverage

3. **Fixed Path Keyword Lists**
   - **Current:** Search relies on hardcoded credential/wallet/cloud-config path keywords
   - **Impact:** Stealer using unlisted paths or excluded process names would not surface
   - **Recommendation:** Implement behavior-based detection (archive + network exfil) independent of specific paths

### Lessons Learned

**What Worked:**
✅ **Multi-phase correlation approach** successfully identified normal patterns and excluded false positives

✅ **Detailed investigation process** properly attributed test-harness activity to authorized testing

**What Didn't Work:**

❌ **No behavior-based fallback** - Relies on specific path/process names rather than pure behavioral chains

**Detection Gap Assessment:**
- **Gap Closed:** Validated that archive-stage-delete pattern is NOT currently occurring at scale
