# H-0003: Lateral Movement via RDP Hunt

## Hypothesis

Adversaries are using RDP to move laterally between Windows hosts after initial compromise.

## Investigation Summary

**Outcome:** 2 True Positives, 1 Detection Created

### Findings

| ID | Source Host | Dest Host | User | Status | Description |
|----|-------------|-----------|------|--------|-------------|
| F-001 | WS-001 | DC-001 | compromised_user | TRUE POSITIVE | Suspicious RDP from workstation to domain controller |
| F-002 | WS-002 | APP-001 | admin_user | TRUE POSITIVE | RDP to production app server from compromised workstation |
| F-003 | JUMP-001 | DB-001 | dba_user | FALSE POSITIVE | Legitimate DBA access via jump host |

### Detection Created

```yaml
title: RDP Connection from Workstation to Server
id: b2c3d4e5-f6a7-8901-bcde-f12345678901
status: test
description: Detects RDP connections originating from workstations to servers
references:
    - https://attack.mitre.org/techniques/T1021/001/
author: Demo Hunter
date: 2025/09/10
logsource:
    product: windows
    service: security
detection:
    selection:
        EventID: 4624
        LogonType: 10  # Remote Interactive
    source_workstation:
        WorkstationName|contains: 'WS-'
    destination_server:
        Computer|contains:
            - 'DC-'
            - 'APP-'
            - 'DB-'
    filter_jump_host:
        WorkstationName|contains: 'JUMP-'
    condition: selection and source_workstation and destination_server and not filter_jump_host
falsepositives:
    - IT administrative access from workstations
    - Help desk remote support
level: high
tags:
    - attack.lateral_movement
    - attack.t1021.001
```

## Business Impact

Detected lateral movement campaign. Isolated 2 compromised workstations. Created detection rule for future prevention.
