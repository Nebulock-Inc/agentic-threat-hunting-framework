## LEARN: Prepare the Hunt

### Hypothesis Statement

**Adversaries inject malicious code into legitimate processes to execute payloads while evading detection, appearing as trusted processes to bypass security controls and gain elevated privileges.**

This hunt uses **behavior-based detection** focusing on anomalous parent-child process chains and cross-process operations that indicate process injection attempts across Windows, Linux, and macOS endpoints.

## OBSERVE: Expected Behaviors

### What Normal Looks Like

**Legitimate parent-child process chains:**

- **Windows:**
  - `services.exe` → `svchost.exe` (Windows service hosting)
  - `explorer.exe` → `cmd.exe` (user-initiated command prompt)
  - `chrome.exe` → `chrome.exe` (browser multi-process architecture)
  - `svchost.exe` (with `-k` parameter) → system utilities
  - System Management Controller (SCCM): `CcmExec.exe` → `powershell.exe`
  - Software deployment tools: `PDQDeployRunner.exe` → various executables

- **Linux:**
  - `systemd` → `bash` (service startup)
  - `sshd` → `bash` (SSH session)
  - `cron` → scripts (scheduled tasks)
  - Package managers: `apt` → `dpkg` → post-install scripts

- **macOS:**
  - `launchd` → various services (macOS service manager)
  - `Terminal.app` → `bash` (user-initiated shell)
  - `Finder` → applications (user double-click)
  - Legitimate software updates: `softwareupdated` → installers

**Legitimate temp directory usage:**
- Software installers extracting to temp, executing signed binaries
- Browser downloads executed from Downloads folder (signed, user-initiated)
- Admin scripts in documented temp paths with known signatures

### What Suspicious Looks Like

**Anomalous injection patterns:**

1. **Office/Browser → Shell → System Utilities** (Macro/exploit-based injection)
   - `winword.exe` → `powershell.exe` → `rundll32.exe`
   - `excel.exe` → `cmd.exe` → `wmic.exe`
   - `chrome.exe` → `cmd.exe` → `net.exe` (NOT typical browser behavior)

2. **Unsigned/Unknown → Signed System Process** (Code injection)
   - `C:\Users\[user]\AppData\Local\Temp\unknown.exe` → `explorer.exe` (from temp dir)
   - `C:\ProgramData\malware.exe` → `svchost.exe` (non-standard location)

3. **System Process with Wrong Parent** (Process hollowing)
   - `svchost.exe` with parent != `services.exe`
   - `explorer.exe` with parent != `userinit.exe` or another `explorer.exe`
   - `lsass.exe` with parent != `wininit.exe`

4. **Cross-Process Memory Access to High-Value Targets**
   - Any process → `lsass.exe` (credential dumping via injection)
   - Temp directory binaries → `svchost.exe`, `explorer.exe`
   - Unsigned processes accessing signed system processes

5. **Reflective Injection Command-Line Indicators**
   - Command lines containing: `ReflectiveLoader`, `Invoke-ReflectivePEInjection`, `Start-Process -WindowStyle Hidden`
   - Base64-encoded PowerShell with injection keywords
   - `rundll32.exe` with unusual DLL paths or exported function names

### Expected Observables

- **Processes:**
  - Target processes: `lsass.exe`, `svchost.exe`, `explorer.exe`, `browser processes`, `systemd`, `bash`
  - Injector indicators: Unsigned binaries, temp directory execution, unusual parent chains
  - Command-line patterns: Reflective loading, encoded commands, process hollowing keywords

- **Network:** (Secondary pivot after process anomaly detected)
  - Outbound connections from injected processes to unusual destinations
  - C2 callback patterns from legitimate process names (post-injection)

- **Files:**
  - Unsigned executables in temp directories (`C:\Users\[user]\AppData\Local\Temp\`, `/tmp/`, `~/Library/Caches/`)
  - Suspicious DLLs loaded by legitimate processes
  - PE files with mismatched internal/external names

- **Authentication:** (Tertiary pivot for lateral movement)
  - Post-injection authentication attempts from injected processes
  - Credential access followed by lateral movement

#### Query 1: Unsigned/Unusual Binaries Spawning System Processes

**Strategy:** Detect processes spawned from suspicious paths (temp directories, downloads) targeting legitimate system processes.

```sql
-- T1055 Process Injection - Temp Directory Suspicious Parent Chains
-- No LIMIT: Returns all results (filter benign activity, paginate if needed)
-- Time-bounded: Last 7 days

SELECT
    time,
    endpoint.name AS hostname,
    endpoint.os.type AS os,
    nebulock_organization_id AS org_id,
    parent.process.name AS parent_process,
    parent.process.file.path AS parent_path,
    process.name AS child_process,
    process.file.path AS child_path,
    process.command_line AS command_line,
    process.user.name AS user
FROM nocsf_unified_events
WHERE
    -- Time bound: Last 7 days
    time >= now() - INTERVAL 7 DAY

    -- Parent process from suspicious locations
    AND (
        parent.process.file.path LIKE '%\\AppData\\Local\\Temp\\%'  -- Windows temp
        OR parent.process.file.path LIKE '%\\Users\\%\\Downloads\\%'  -- Windows downloads
        OR parent.process.file.path LIKE '%/tmp/%'  -- Linux/macOS temp
        OR parent.process.file.path LIKE '%/var/tmp/%'  -- Linux temp
        OR parent.process.file.path LIKE '%/Library/Caches/%'  -- macOS cache
        OR parent.process.file.path LIKE '%\\ProgramData\\%'  -- Windows non-standard
    )

    -- Child process is legitimate system process (high-value targets)
    AND (
        -- Windows targets
        process.name IN ('explorer.exe', 'svchost.exe', 'lsass.exe', 'rundll32.exe', 'regsvr32.exe', 'wmic.exe', 'mshta.exe')
        -- Linux/macOS targets
        OR process.name IN ('bash', 'sh', 'zsh', 'python', 'python3', 'curl', 'wget', 'systemd', 'launchd')
    )

    -- Exclude known false positives (legitimate installers)
    AND parent.process.name NOT IN (
        'setup.exe', 'installer.exe', 'update.exe',  -- Common installer names
        'GoogleUpdate.exe', 'ChromeSetup.exe',  -- Browser updates
        'TeamViewer_Setup.exe', 'Zoom_Setup.exe'  -- Remote software
    )

    -- Exclude legitimate admin users (refine based on customer)
    AND process.user.name NOT LIKE '%admin%'
    AND process.user.name NOT LIKE '%svc%'

ORDER BY time DESC;
```

**Query Notes:**
- **No LIMIT:** Returns all results (filter benign activity, paginate analysis if needed)
- Time-bounded to 7 days for performance
- Targets temp directory execution spawning system processes
- Platform-agnostic (works across Windows, Linux, macOS)
- **Benign filtering strategy:** If results are large, add org-specific filters or exclude known installers iteratively
- **Pagination strategy:** If analysis needed, use `LIMIT X OFFSET Y` or analyze by organization/hostname

#### Query 2: Office/Browser Apps Spawning Shell Utilities (Macro/Exploit-Based Injection)

**Strategy:** Detect Office applications or browsers spawning command shells or system utilities (common macro/exploit chain).

```sql
-- T1055 Process Injection - Office/Browser Spawning Shells
-- Detects macro-based and browser exploit chains

SELECT
    time,
    endpoint.name AS hostname,
    endpoint.os.type AS os,
    nebulock_organization_id AS org_id,
    parent.process.name AS parent_process,
    process.name AS child_process,
    process.command_line AS command_line,
    process.user.name AS user
FROM nocsf_unified_events
WHERE
    time >= now() - INTERVAL 7 DAY

    -- Parent: Office apps or browsers
    AND parent.process.name IN (
        'winword.exe', 'excel.exe', 'powerpnt.exe', 'outlook.exe',  -- Office
        'chrome.exe', 'firefox.exe', 'msedge.exe', 'safari',  -- Browsers
        'WINWORD.EXE', 'EXCEL.EXE', 'POWERPNT.EXE'  -- Case variations
    )

    -- Child: Shells or system utilities
    AND process.name IN (
        'powershell.exe', 'cmd.exe', 'wscript.exe', 'cscript.exe',  -- Windows shells
        'rundll32.exe', 'regsvr32.exe', 'mshta.exe', 'wmic.exe',  -- Windows utilities
        'bash', 'sh', 'zsh', 'python', 'curl', 'wget'  -- Linux/macOS shells
    )

    -- Exclude legitimate Office add-ins (refine based on FPs)
    AND process.command_line NOT LIKE '%Microsoft\\Office\\%'
    AND process.command_line NOT LIKE '%Program Files%'

ORDER BY time DESC;
```

**Query Notes:**
- **No LIMIT:** Returns all results (filter benign activity, paginate analysis if needed)
- High-confidence pattern: Office/Browser → Shell = common injection vector
- Catches macro-based malware, browser exploits, phishing payloads
- Expected FPs: Legitimate Office VBA scripts, browser extensions (filter in analysis phase)
- **Benign filtering strategy:** If large results, exclude known command-line patterns (`%\\Office\\%`, legitimate script paths)
- **Pagination strategy:** Analyze by parent_process or organization for manageable batches

#### Query 3: System Processes with Unexpected Parents (Process Hollowing)

**Strategy:** Detect legitimate system processes spawned by non-standard parents (process hollowing indicator).

```sql
-- T1055.012 Process Hollowing - System Processes with Wrong Parents
-- Detects svchost.exe, lsass.exe, explorer.exe with unexpected parents

SELECT
    time,
    endpoint.name AS hostname,
    endpoint.os.type AS os,
    nebulock_organization_id AS org_id,
    parent.process.name AS parent_process,
    parent.process.file.path AS parent_path,
    process.name AS child_process,
    process.file.path AS child_path,
    process.user.name AS user
FROM nocsf_unified_events
WHERE
    time >= now() - INTERVAL 7 DAY

    -- Windows process hollowing targets
    AND endpoint.os.type IN ('Windows', 'windows')

    -- Target processes with expected parents
    AND (
        -- svchost.exe should ONLY be spawned by services.exe
        (process.name = 'svchost.exe' AND parent.process.name != 'services.exe')

        -- lsass.exe should ONLY be spawned by wininit.exe
        OR (process.name = 'lsass.exe' AND parent.process.name != 'wininit.exe')

        -- explorer.exe should be spawned by userinit.exe or another explorer.exe
        OR (process.name = 'explorer.exe'
            AND parent.process.name NOT IN ('userinit.exe', 'explorer.exe'))

        -- winlogon.exe should be spawned by smss.exe
        OR (process.name = 'winlogon.exe' AND parent.process.name != 'smss.exe')
    )

    -- Exclude monitoring tools that may legitimately spawn these processes
    AND parent.process.name NOT IN (
        'CSFalconService.exe',  -- CrowdStrike
        'SentinelAgent.exe',  -- SentinelOne
        'MsMpEng.exe'  -- Windows Defender
    )

ORDER BY time DESC;
```

**Query Notes:**
- **No LIMIT:** Returns all results (expected very low volume due to high specificity)
- Windows-specific (process hollowing most common on Windows)
- Very high-confidence detections (system process parentage is rigid)
- Low FP rate expected (filter out EDR/monitoring tools)
- **Benign filtering strategy:** If any FPs occur, add to parent exclusion list (EDR/backup/management tools)
- **Pagination strategy:** Unlikely needed (low volume), but can analyze by process.name if needed (svchost, lsass, explorer separately)

#### Query 4: Cross-Process Memory Access to LSASS (Credential Dumping via Injection)

**Strategy:** Detect processes accessing lsass.exe (credential dumping via injection) - **HIGHEST PRIORITY**.

**Note:** This query targets *access to* lsass.exe, not lsass.exe itself. Requires process access event types (not all EDR logs this).

```sql
-- T1055 + T1003.001 - Process Injection to LSASS for Credential Dumping
-- Detects processes accessing lsass.exe memory (mimikatz, procdump, etc.)

SELECT
    time,
    endpoint.name AS hostname,
    endpoint.os.type AS os,
    nebulock_organization_id AS org_id,
    process.name AS accessor_process,
    process.file.path AS accessor_path,
    process.command_line AS command_line,
    process.user.name AS user
FROM nocsf_unified_events
WHERE
    time >= now() - INTERVAL 7 DAY

    -- Target: lsass.exe being accessed
    AND (
        process.command_line LIKE '%lsass%'
        OR process.command_line LIKE '%lsass.exe%'
        OR process.command_line LIKE '%lsass.dmp%'
    )

    -- Accessor process indicators (dumping tools)
    OR process.name IN (
        'procdump.exe', 'procdump64.exe',  -- Sysinternals
        'mimikatz.exe',  -- Direct mimikatz
        'taskmgr.exe',  -- Task Manager dump
        'rundll32.exe'  -- comsvcs.dll method
    )

    -- Exclude legitimate access from monitoring/security tools
    AND process.name NOT IN (
        'CSFalconService.exe', 'CSFalconContainer.exe',  -- CrowdStrike
        'SentinelAgent.exe', 'SentinelAgentWorker.exe',  -- SentinelOne
        'MsMpEng.exe',  -- Windows Defender
        'HealthService.exe',  -- SCOM
        'VeeamAgent.exe', 'Commvault.exe'  -- Backup agents
    )

ORDER BY time DESC;
```

**Query Notes:**
- **No LIMIT:** Returns all results (critical severity = review all findings)
- Combines T1055 (injection) + T1003.001 (LSASS dumping)
- Very high-priority detection (credential theft in progress)
- References H-0004 lessons (eviltwin.exe using process hollowing for LSASS)
- FPs: Backup agents, monitoring tools (pre-filtered)
- **Benign filtering strategy:** If large results, add known admin tools to exclusion list or filter by nebulock_organization_id
- **Pagination strategy:** Analyze by org_id for manageable batches (prioritize production orgs over test environments)

### Lessons Learned

**What Worked Well:**

- **Progressive refinement strategy**: Starting broad (12K-541K results) then applying targeted filters drastically reduced noise (→ 16-37 results)
- **Query 4 (LSASS Dumping) refinement**: Focusing on high-confidence indicators (procdump + lsass, comsvcs.dll MiniDump) reduced 541K results to 16 manageable findings
- **Query 2 browser extension filtering**: Adding exclusions for known benign patterns (1Password, BrowserCore, IE Tab) reduced 12,789 results to 37
- **Time-bounded queries (7 days)**: All queries completed in 3-17 seconds despite scanning 1.5B+ rows
- **ClickHouse performance**: Indexed fields (process.name, parent.process.name, time) enabled fast filtering on massive dataset

**What Could Be Improved:**

- **Query 3 (Process Hollowing) too noisy**: 14,673 results dominated by normal Windows behavior (rpcnet.exe, svchost.exe). Needs additional filters:
  - Exclude known management tools (Box.exe, rpcnet.exe, TPQMAssistant.exe)
  - Focus on parent_path anomalies (null paths, unusual locations)
