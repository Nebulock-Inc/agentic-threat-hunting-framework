# H-0001: Endpoint Credential Access Hunt

## Hypothesis

Adversaries are accessing credential stores (LSASS, keychain) across the endpoint fleet to harvest credentials for lateral movement.

## Investigation Summary

**Outcome:** 1 True Positive, 1 Detection Created

### Findings

| ID | Host | User | Technique | Status | Description |
|----|------|------|-----------|--------|-------------|
| F-001 | WIN-HOST-001 | user01 | T1003.001 | TRUE POSITIVE | Unauthorized LSASS memory access via procdump.exe |
| F-002 | MAC-HOST-001 | user02 | T1555.001 | FALSE POSITIVE | Legitimate password manager keychain access |

### Queries Executed

```sql
-- Windows LSASS access
SELECT * FROM process_events 
WHERE target_process = 'lsass.exe'
AND access_mask & 0x1010 > 0
LIMIT 1000;

-- macOS keychain dumps
SELECT * FROM process_events
WHERE process_name = 'security'
AND command_line LIKE '%dump-keychain%'
LIMIT 1000;
```

## Detection Created

```yaml
title: LSASS Memory Access via Suspicious Process
id: a1b2c3d4-e5f6-7890-abcd-ef1234567890
status: test
description: Detects suspicious processes accessing LSASS memory for credential dumping
references:
    - https://attack.mitre.org/techniques/T1003/001/
author: Demo Hunter
date: 2025/10/22
logsource:
    category: process_access
    product: windows
detection:
    selection:
        TargetImage|endswith: '\lsass.exe'
        GrantedAccess|contains:
            - '0x1010'
            - '0x1410'
            - '0x1438'
    filter_legitimate:
        SourceImage|startswith:
            - 'C:\Windows\System32\'
            - 'C:\Program Files\Windows Defender\'
    condition: selection and not filter_legitimate
falsepositives:
    - Legitimate security tools
    - Backup software
level: high
tags:
    - attack.credential_access
    - attack.t1003.001
```

## Business Impact

Detected 1 credential theft attempt. Created detection rule preventing future occurrences. No lateral movement observed from compromised credentials.
