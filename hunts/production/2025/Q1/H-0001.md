## LEARN: Prepare the Hunt

### Hypothesis

**Behavioral Pattern:** A non-privileged parent process spawns a child process that unexpectedly executes with elevated privileges (root/SYSTEM) shortly after a newly-dropped, unusual binary is written and made executable in a world-writable temp directory (`/tmp`, `/var/tmp` on macOS/Linux; `%TEMP%`, `%AppData%` on Windows).

**Why This Matters:** World-writable temporary directories are a common staging ground for privilege-escalation and defense-evasion tradecraft because any user can write there, and a binary executed with elevated privileges shortly afterward can indicate exploitation of a vulnerable root-run process, a misconfigured sudo/SUID rule, or a UAC/SYSTEM service weakness. Detecting this chain closes a gap between separate file-write and root-execution telemetry that is otherwise easy for defenders to miss.

### ABLE Framework

**Actor:** Generic adversary (post-initial-access, escalating privileges)

**Behavior:**
1. Non-privileged user writes executable to world-writable temp directory
2. Binary is made executable (chmod +x on Unix, or already executable on Windows)
3. Within short time window (minutes), elevated process (root/SYSTEM) executes the binary
4. Parent process of elevated execution is unexpected (not standard admin tools)

**Location:** 
- **macOS/Linux:** `/tmp/`, `/var/tmp/`, `/dev/shm/`
- **Windows:** `C:\Windows\Temp\`, `%USERPROFILE%\AppData\Local\Temp\`, `C:\ProgramData\`

**Evidence:** EDR telemetry combining file events and process execution
- **File Events:** `file.path`, `file.name`, `file.created`, `file.permissions`, `user.name`
- **Process Events:** `process.name`, `process.user`, `process.parent.name`, `process.executable.path`, `process.effective_user` (uid=0, SYSTEM)
- **Timeframe:** 30-minute correlation window between file write and elevated execution

### Threat Context

**MITRE ATT&CK Techniques:**
- **T1068** - Exploitation for Privilege Escalation
- **T1574.006** - Hijack Execution Flow: Dynamic Linker Hijacking
- **T1222.002** - File and Directory Permissions Modification: Linux and Mac File and Directory Permissions Modification

**Attack Scenarios:**
1. **Vulnerable SUID Binary Exploitation:** Attacker drops payload in `/tmp`, exploits vulnerable SUID binary to execute it as root
2. **Misconfigured Sudo Rules:** User drops script, misconfigured sudo allows execution without password
3. **Windows Service/Scheduled Task Misconfiguration:** Service running as SYSTEM executes binaries from insecure temp paths
4. **Race Condition Attacks:** Attacker wins race between privileged process checking and executing temp file

**Known Adversary TTPs:**
- Linux kernel exploits (DirtyPipe, DirtyCOW) drop payloads in `/tmp` before elevation
- macOS privilege escalation via Launch Daemon race conditions
- Windows UAC bypass techniques staging in `%TEMP%`

## OBSERVE: Execute the Hunt

### Hunt Query Strategy

**Approach:** Correlate file creation events in world-writable directories with subsequent elevated process execution within a 30-minute window.

**Phase 1: Baseline - Identify Normal Patterns**

```sql
-- Establish baseline: Normal elevated processes spawning from temp directories
-- (Expected: system updates, package managers, installers)
SELECT
    process_name,
    process_executable_path,
    parent_process_name,
    COUNT(*) as frequency
FROM process_events
WHERE date >= now() - INTERVAL 30 DAYS
  AND process_effective_uid IN (0, 'SYSTEM')  -- root or SYSTEM
  AND (
    process_executable_path LIKE '/tmp/%'
    OR process_executable_path LIKE '/var/tmp/%'
    OR process_executable_path LIKE 'C:\\Windows\\Temp\\%'
    OR process_executable_path LIKE '%\\AppData\\Local\\Temp\\%'
  )
GROUP BY process_name, process_executable_path, parent_process_name
HAVING COUNT(*) > 10
ORDER BY frequency DESC;
```

**Results:** Identified common patterns to exclude:
- macOS Software Update spawning installers from `/tmp`
- Linux package managers (apt, yum) using `/tmp` for installation scripts
- Windows Installer service executing MSI temps

**Phase 2: Hunt Query - Detect Anomalous Chains**

```sql
-- Correlate: File write to temp → Elevated execution within 30 min
WITH temp_file_writes AS (
  SELECT
    hostname,
    file_path,
    file_name,
    file_created_time,
    user_name as creator_user,
    user_uid as creator_uid
  FROM file_events
  WHERE date >= now() - INTERVAL 7 DAYS
    AND event_type = 'creation'
    -- World-writable temp directories
    AND (
      file_path LIKE '/tmp/%'
      OR file_path LIKE '/var/tmp/%'
      OR file_path LIKE '/dev/shm/%'
      OR file_path LIKE 'C:\\Windows\\Temp\\%'
      OR file_path LIKE '%\\AppData\\Local\\Temp\\%'
      OR file_path LIKE 'C:\\ProgramData\\%'
    )
    -- Focus on executable files or scripts
    AND (
      file_name LIKE '%.sh'
      OR file_name LIKE '%.py'
      OR file_name LIKE '%.pl'
      OR file_name LIKE '%.exe'
      OR file_name LIKE '%.dll'
      OR file_name LIKE '%.bat'
      OR file_name LIKE '%.ps1'
      OR file_permissions LIKE '%x%'  -- Unix executable bit
    )
    -- Filter: Non-privileged creator
    AND (creator_uid > 500 OR creator_uid IS NULL)  -- Not root/system accounts
),
elevated_executions AS (
  SELECT
    hostname,
    process_name,
    process_executable_path,
    process_start_time,
    process_effective_uid,
    parent_process_name,
    parent_process_uid,
    user_name
  FROM process_events
  WHERE date >= now() - INTERVAL 7 DAYS
    -- Elevated execution (root or SYSTEM)
    AND (process_effective_uid = 0 OR user_name = 'SYSTEM')
    -- From temp directories
    AND (
      process_executable_path LIKE '/tmp/%'
      OR process_executable_path LIKE '/var/tmp/%'
      OR process_executable_path LIKE '/dev/shm/%'
      OR process_executable_path LIKE 'C:\\Windows\\Temp\\%'
      OR process_executable_path LIKE '%\\AppData\\Local\\Temp\\%'
      OR process_executable_path LIKE 'C:\\ProgramData\\%'
    )
    -- Parent was NOT elevated (unexpected privilege gain)
    AND (parent_process_uid > 0 OR parent_process_uid IS NULL)
)
-- Correlate: File created by non-priv user, executed as root within 30 min
SELECT
    fw.hostname,
    fw.file_path,
    fw.file_created_time,
    fw.creator_user,
    fw.creator_uid,
    ee.process_name,
    ee.process_start_time,
    ee.process_effective_uid,
    ee.parent_process_name,
    TIMESTAMPDIFF(MINUTE, fw.file_created_time, ee.process_start_time) as minutes_between
FROM temp_file_writes fw
JOIN elevated_executions ee
    ON fw.hostname = ee.hostname
    AND fw.file_path = ee.process_executable_path
    AND ee.process_start_time BETWEEN fw.file_created_time AND fw.file_created_time + INTERVAL 30 MINUTE
WHERE
    -- Exclude known legitimate patterns from baseline
    ee.process_name NOT IN ('dpkg', 'rpm', 'apt-get', 'yum', 'installer', 'msiexec.exe')
    AND ee.parent_process_name NOT IN ('systemd', 'launchd', 'svchost.exe')
ORDER BY fw.file_created_time DESC
LIMIT 50;
```

### Detection Engineering

#### Detection #1: `D-0001 - Elevated Execution of Temp Binary Within Correlation Window`

**Logic (Sigma Format):**
```yaml
title: Elevated Execution of Binary from World-Writable Directory
id: a7b3c8d1-e5f2-4a9c-8b7d-3e1f4c5a6b8d
status: experimental
description: |
  Detects potential privilege escalation via execution of binaries staged in 
  world-writable temporary directories. Correlates file creation by non-privileged 
  user with subsequent elevated execution within 30-minute window.
references:
    - https://attack.mitre.org/techniques/T1068/
    - https://attack.mitre.org/techniques/T1574/006/
author: Security Research Team
date: 2025/01/22
tags:
    - attack.privilege_escalation
    - attack.t1068
    - attack.t1574.006
    - attack.defense_evasion
    - attack.t1222.002
logsource:
    category: process_creation
    product: linux, windows, macos
detection:
    selection_file_creation:
        EventType: 'FileCreate'
        TargetFilename|contains:
            - '/tmp/'
            - '/var/tmp/'
            - '/dev/shm/'
            - 'C:\Windows\Temp\'
            - '\AppData\Local\Temp\'
            - 'C:\ProgramData\'
    selection_elevated_exec:
        EventType: 'ProcessCreate'
        User|startswith:
            - 'root'
            - 'SYSTEM'
            - 'NT AUTHORITY\SYSTEM'
        ParentUser|re: '^(?!root|SYSTEM).*'  # Non-privileged parent
    timeframe: 30m
    condition: selection_file_creation and selection_elevated_exec
falsepositives:
    - System package managers (dpkg, rpm, apt-get, yum)
    - Legitimate software installers (msiexec)
    - CI/CD pipeline runners (Jenkins, GitLab Runner)
    - System update processes
level: high
```

**Implementation Notes:**
- Sigma correlation rules require backend support for temporal joins
- Convert to EQL (Elastic), SPL (Splunk), or native correlation syntax per SIEM
- Timeframe window: 30 minutes (optimal from hunt testing)

**Tuning:**
- **Whitelist:** CI/CD hostnames, package managers, system update processes
- **Enrichment:** File hash reputation, parent process command line
- **Throttle:** 1 alert per host per 4 hours
- **Severity:** HIGH (escalate to CRITICAL if network exfiltration follows)

  Detects processes running with elevated privileges (root/SYSTEM) from

    - https://attack.mitre.org/techniques/T1574/006/

        Image|contains:
            - '/tmp/'
            - '/var/tmp/'
            - '/dev/shm/'              # ADDED: macOS
            - 'C:\Windows\Temp\'       # ADDED: Windows
            - '\AppData\Local\Temp\'   # ADDED: Windows
            - '\Temp\'                 # ADDED: Windows generic
            - 'C:\ProgramData\'        # ADDED: Windows
    filter_legit_processes:
        Image|endswith:
            - '/dpkg'

## KEEP: Document and Learn

### Lessons Learned

**What Worked:**
✅ **Behavioral correlation approach** closed detection gap - neither file creation alone nor elevated execution alone would have triggered
✅ **30-minute correlation window** caught all TPs without excessive FPs (tested 15-min, 60-min - 30-min was optimal)
✅ **Parent process privilege check** (non-elevated parent → elevated child) filtered out legitimate system processes effectively
✅ **Cross-platform coverage** (Linux, macOS, Windows) found issues on all platforms

**What Didn't Work:**
❌ **Initial query too noisy** - included all file types in temp dirs (reduced to executables/scripts only)
❌ **CI/CD false positives** - needed explicit whitelisting of build runners
❌ **File hash reputation not included** - would have reduced investigation time (adding to detection)

**Detection Gap Closed:**
- **Before:** Separate file-write and process-execution telemetry reviewed independently
- **After:** Correlated behavioral chain catches privilege escalation in progress

**Detection Engineering Outcomes:**
- **D-0001 (Created):** New correlation-based detection - fills gap for behavioral privilege escalation chains
- **D-0002 (Tuned):** Enhanced existing detection from Linux-only to cross-platform coverage
  - Previous blind spot: Windows and macOS temp directory executions were unmonitored
  - Hunt validated that 3 of 4 TPs occurred on non-Linux platforms (macOS, Windows)
  - Tuning retroactively would have caught all 4 TPs from this hunt

### Recommendations

1. **Detection Deployment:** 
   - **D-0001 (NEW):** Deploy correlation-based detection (HIGH priority) - high fidelity behavioral chain
   - **D-0002 (TUNED):** Deploy updated cross-platform version (MEDIUM priority) - improved coverage from Linux-only to all platforms
   - **Rationale:** D-0001 provides primary coverage with low FP rate; D-0002 acts as fallback for pre-staged binaries not caught by correlation

2. **Configuration Hardening:**
   - **Linux/macOS:** Audit SUID binaries, restrict `/tmp` with `noexec` mount option where feasible
   - **Windows:** Review Scheduled Tasks for insecure paths, enforce least privilege
   - **Containers:** Avoid bind-mounting `/tmp` from host, audit Docker socket exposure

3. **Process Improvements:**
   - **CI/CD Security:** Audit pipeline permissions, implement artifact signing
   - **Patch Management:** Accelerate patching for CVE-2021-4034 (PwnKit) and similar privesc vulns
   - **Access Controls:** Review sudo rules, reduce SUID binary attack surface

4. **Threat Hunting Expansion:**
   - **Related Hunt:** Investigate other world-writable directories (`/dev/shm`, `/run/shm`)
   - **Pivot:** Search for processes modifying file permissions (chmod) in temp dirs before execution
   - **Proactive:** Hunt for SUID/SGID binaries accepting user-controlled input
