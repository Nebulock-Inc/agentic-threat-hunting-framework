# H-0005: Data Exfiltration via Cloud Storage Hunt

## Hypothesis

Insiders or compromised accounts are exfiltrating sensitive data to personal cloud storage accounts (Dropbox, Google Drive, OneDrive).

## Investigation Summary

**Outcome:** 1 Security Incident Identified

### Finding

**F-001: Unauthorized Data Upload to Personal Dropbox**
- **User:** contractor_user
- **Host:** WS-005
- **Data:** 2.3 GB of source code archives
- **Timestamp:** 2025-03-12 14:23 UTC
- **Destination:** dropbox.com (personal account)
- **Status:** CONFIRMED EXFILTRATION

### Investigation Details

Contractor uploaded proprietary source code to personal Dropbox account 3 days before contract end date. Files included:
- Internal API documentation
- Database schemas
- Authentication token examples

### Queries Executed

```sql
-- Large uploads to cloud storage domains
SELECT 
    user,
    host,
    destination_domain,
    SUM(bytes_out) as total_uploaded
FROM network_events
WHERE destination_domain IN ('dropbox.com', 'drive.google.com', 'onedrive.live.com')
AND bytes_out > 100000000  -- > 100MB
GROUP BY 1,2,3
HAVING total_uploaded > 1000000000;  -- > 1GB
```

## Business Impact

**CRITICAL INCIDENT:** Confirmed intellectual property theft. Legal action initiated. Contractor access terminated. All source code rotated.
